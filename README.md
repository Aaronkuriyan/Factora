# Factora - Fake News Detector

A web application that detects fake news and verifies the credibility of news articles.

## Features

- ✅ Submit news articles for fact-checking
- ✅ Real-time verification against fact-checking APIs
- ✅ Display credibility score and analysis
- ✅ User-friendly interface

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js with Express
- **Detection:** Fact-checking API integration
- **Styling:** CSS

## Project Structure

```
Factora/
├── frontend/          # React application
├── backend/           # Node.js Express server
├── README.md
└── .gitignore
```

## Getting Started

### Prerequisites
- Node.js (v14+)
- npm or yarn

### Installation

#### Backend Setup
```bash
cd backend
npm install
npm start
```

#### Frontend Setup
```bash
cd frontend
npm install
npm start
```

The application will be available at `http://localhost:3000`

## API Integration

This project integrates with fact-checking APIs to verify news articles:
- Google Fact Check API
- NewsAPI
